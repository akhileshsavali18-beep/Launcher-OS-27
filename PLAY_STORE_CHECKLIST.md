## Release
- Build signed Android App Bundle (.aab) for Google Play
- Keep the same applicationId: com.aistudio.launcheros.mrtq
- Increase versionCode for every update
- Keep the same signing key
- Add release notes
- Test internal/closed track as required
- Roll out to production

Google Play requires new apps to use Android App Bundles, and updates must keep the same package name, use a higher versionCode, and be signed consistently.
